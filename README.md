# Press Sense — Premium Industrial Product Catalogue

Production-quality B2B industrial machinery, digital-offset finishing, and precision printing-solutions catalogue for **PRESS SENSE** (Est. 2010, Delhi, India).

Designed with an **Apple-like minimalist product presentation** meets **Swiss editorial layout**, engineered around WhatsApp sales lead generation and direct technical consultation.

---

## Key Features

- **Direct WhatsApp Conversion Funnel**: Dynamic click-to-chat links with pre-filled machine names, part codes, and spec inquiries.
- **Desktop Mega Menu**: Large dropdown on hover with category imagery, descriptions, and dynamically calculated product counts.
- **Mobile Navigation Drawer**: Collapsible category accordion and search optimized for touch devices.
- **Global Search Modal (`⌘K` / `Ctrl+K`)**: Live multi-attribute search across machines, categories, features, and model codes.
- **Controlled Image Pipeline**: Strict `aspect-ratio: 4/3` and `object-fit: contain` so industrial machinery is never awkwardly cropped.
- **Product Gallery Lightbox**: Main view with thumbnail strip, mobile swipe, keyboard navigation, and fullscreen modal viewer.
- **RFQ Quote Modal**: Direct quotation request form pre-filling machine details and transmitting to the WhatsApp sales desk.
- **Complete Technical Specifications**: Formatted tables detailing cutting heights, motor ratings, plies, and metallurgy.
- **SEO & Structured Data**: Built-in JSON-LD `Product` schema, OpenGraph metadata, `sitemap.xml`, and `robots.txt`.

---

## Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4 (Flat palette, zero gradients)
- **Icons**: Lucide React
- **Typography**: Google Fonts (Manrope for headings, Inter for body/UI)
- **Carousel**: Embla Carousel

## Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Run the development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for production
```bash
npm run build
npm start
```
